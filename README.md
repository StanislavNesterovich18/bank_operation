# Учебный проект по Python

Анализатор финансовых транзакций: загружает данные из Excel-файла, фильтрует и группирует операции, строит отчёты.

---
## Реализация функций
1. `get_mask_card_number()`   
Функция возвращает скрытый номер карты в формате:`1234 56** **** 7890`.
2. `get_mask_account()`  
Функция возвращает скрытый номер счета в формате:`**1234`.
3. `mask_account_card()`  
Функция определяет формат данных счет/карта, далее с помощью соответствующих   
функций `1` и `2` скрывает номер. Возвращает в формате:`ИМЯ КАРТЫ 1234 56** **** 7890`  
или `счет ** 7890`.
 4. `get_date()`  
Функция возвращает строку с датой в формате:`ДД.ММ.ГГГГ`.
 5. `filter_by_state()`  
Функция фильтрует словари по заданному значению для ключа `state`.
 6. `sort_by_date()`
Функция возвращает по умолчанию отсортированный по убыванию список по дате.
7. `filter_by_currency()`
Функция возвращать итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной.
8. `transaction_descriptions()`
Принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.
9. `card_number_generator()`
Генератор может сгенерировать номера карт в заданном диапазоне.
10.  `write_log`
Функция записывает результат выполнения функции foo в файл.
11. `log` , `decorator`
Декоратор для логирования с настройками.
12. `financial_transaction`
Функция открывает json файл
13. `amount_transaction`
Функция выводит сумму транзакции
14. `api_currency`
Функция конвертирует валюту через АПИ
15. `read_csv`
Функция чтения из .csv файла
16. `read_xlsx`
Функция чтения из excel файла

## Тестирование
Запуск тестов осуществляется через команду pytest.
- `test_get_data.py` - Данный тест предназначен для тестирования приведения даты в нужный нам формат, а так же для проверки работы функции если нужный нам формат не найден.
- `test_masks.py` и `test_masks_account.py`- Данные тесты предназначены для тестирования функций маскировки номера банковской карты и счета.
- `test_processing.py` - Тестирует функцию которая возвращает новый отсортированный список славорей по заданному слову, а так же сортирует по дате 
- `test_widget.py` - Тестирует функцию которая умеет обрабатывать информацию как о картах, так и о счетах. Тестирует функцию которая принимает дату/время, возвращает дату в формате ДД.ММ.ГГГГ 
- `test_generators.py` - Тестирует функции которые принимают на вход список словарей, представляющих транзакции и возвращают итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной (например, USD),
а так же принимает список словарей с транзакциями и возвращает описание каждой операции по очереди и который выдает номера банковских карт в формате `XXXX XXXX XXXX XXXX`, где `X` — цифра номера карты.
- `conftest.py` - Вспомогательный файл который содержит фикстуры.
- `test_decorators.py` - Декоратор должен принимать необязательный аргумент filename, который определяет, куда будут записываться логи (в файл или в консоль)
- `test_mask_account_card` - функция которая тестирует обработку информации о картах.
- `test_get_mask_card_number` - функция которая тестирует обработку информации о счетах.
- `test_financial_transaction` - Функция тестирует открытие json файл
- `test_amount_transaction` - функция тестирует вывод суммы транзакции в рублях
- `test_read_csv` - функция тестирует чтение csv файла
- `test_read_xls` - функция тестирует чтение xlsx файла
